# University Student Record and Campus Route Management System

## CIT300 – Data Structures and Algorithms

**Graded Practical Assignment 1 (Week 10)**

### Project Description

This is a Java console-based application developed for the CIT300 Data Structures and Algorithms module at SLTC Research University.

The system manages university student records and campus routes using multiple data structures, including Linked Lists, Stacks, Queues, BST/AVL Trees, Hashing, and Graphs.

## Features

* Add Student Record
* Update Student Record
* Delete Student Record
* Display All Student Records
* Search Student by Student ID
* Add and Process Service Requests
* Display Recent Actions
* Display Students using BST/AVL
* Search Students using Hashing
* Add and Remove Campus Locations
* Add and Remove Campus Connections
* Display Campus Connections
* Traverse Campus using BFS/DFS
